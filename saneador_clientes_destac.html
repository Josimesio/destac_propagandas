Saneador de Clientes

Importe uma planilha contendo uma coluna de CNPJ. O programa consulta os dados cadastrais, saneia os registros e gera uma nova planilha com os campos do cadastro de clientes. Cliente é global, portanto empresa_id não é gerado.

Fonte padrão: BrasilAPI / Minha Receita, com dados cadastrais oriundos da Receita Federal. Para consulta oficial contratada diretamente no SERPRO/Receita, é necessário usar credenciais próprias da API oficial.
