CORREÇÃO PONTUAL DA PÁGINA INICIAL DESTAC

1. Salve uma cópia do index.html atual.
2. Substitua somente o index.html da raiz do projeto pelo arquivo incluído neste ZIP.
3. Verifique: git diff -- index.html
4. Teste a página e o acesso administrativo.
5. Publique: git add index.html && git commit -m "Corrige conflito Git na pagina inicial" && git push origin main

Não há alterações em clientes, contratos, dashboard, scripts ou banco.
Foi preservado o layout institucional do lado direito do conflito e o favicon oficial.
